# Submission notes

**Project:** Compliance Shelf

**Challenge:** VT × Accenture Build Challenge

**Format:** independent student prototype

**Primary scenario:** VA contract delivery evidence, records protection and simulated program funding

**Additional examples:** SSA funding and VA/SSA benefits intake

## Included

Current application source, eight-service local backend, synthetic documents and fixtures, unit/integration tests, reproducible development tooling, optional infrastructure source and Python video module, and the final narrated demonstration.

The application is a submission snapshot of the local `compliance-platform` workspace. The existing development repository and its remote remain intact. Private development conversations, local credentials, runtime workspaces, model weights, temporary recordings and the separate Replit design experiment are excluded.
